# CE 2.0

Cloud + agent-native interoperability — data exchange and workflows.

## Vision

CE 2.0 is a platform for fully cloud and agent-native interoperability, enabling seamless data exchange and workflow orchestration across systems and AI agents.

## Structure

```
/docs        — Architecture decisions, specs, and design docs
/src         — Source code
  /core      — Interoperability core (data exchange protocols, schema)
  /agents    — Agent orchestration layer
  /workflows — Workflow engine and definitions
  /api       — External API surface
/infra       — Cloud infrastructure (IaC)
```
